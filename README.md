#  Booking Automation Project

This project automates hotel search and validation on [Booking.com](https://www.booking.com/) using **Selenium WebDriver** and **Pytest**. It simulates a complete user journey from selecting dates and location to validating hotel details and saving them in a report.

##  Features

- Automated UI testing with Selenium
- Data-driven testing with Pytest parameterization
- Custom validations for location, date, score, and pricing
- JSON report generation
- HTML test reporting
- Modular Page Object Model (POM) structure

## Tech Used

- Python 3
- Selenium
- Pytest
- JSON
- HTML reporting (`pytest-html`)
